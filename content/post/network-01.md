# 一、学习安排与复习
### （一）复习与作业处理
- 回顾前一天未完成的练习，脚本练习题需提交作业后发放答案，强调代码编写方法不唯一，答案仅作参考，鼓励形成个人思路。
- 周五进行周测，复习时间控制在1-1.5天，无需额外大量投入。

### （二）知识回顾与疑问解答
- 核心复习内容：
  1. 流程控制：分支（case语句）、循环（for循环、while循环、until循环）、异常控制（break跳出循环、exit跳出脚本）；
  2. 文件判断：`-e`（文件存在）、`-f`（普通文件）等测试选项；
  3. 语法差异：单层`[]`与双层``的区别（``更安全，避免字符串拆分/通配符扩展）。
- 疑问解答：语法格式规范、代码留存建议（粘贴到笔记或写成独立脚本）。

- 定义格式：
```bash
# 函数定义基础语法（括号内无参数，函数体用大括号包裹）
函数名() {
  函数执行的命令/逻辑

```
- 调用方式：
  - 本脚本内直接调用：`函数名`；

# 二、网络服务准备——虚拟机配置
### （一）虚拟机数量与备份
- 基础要求：至少4台虚拟机，建议额外准备1台备用机（避免设备故障影响实验）；
- 扩展实验：可根据时间用4台Y47机器重复验证相关服务。

### （二）虚拟机拍照管理
- 初始拍照：系统安装完成后立即拍照，便于快速恢复初始环境；
- 二次拍照：完成基础配置（网卡、yum源、防火墙等）后，命名为“网络服务记录拍照”，推荐打“快章”（占用空间更小）。

### （三）双网卡配置
1. 网卡类型设置：
   - 第一张：仅主机网卡（用于虚拟机间局域网通信）；
   - 第二张：NAT网卡（用于访问公网，可按需开启/关闭）；
   - 注意：网卡可随时添加，不受系统安装时间限制。
2. 配置文件生成（装系统后添加的网卡默认无配置文件）：
```bash
# 复制已有网卡配置文件（以ens160为模板，生成ens256配置）
cp /etc/sysconfig/network-scripts/ifcfg-ens160 /etc/sysconfig/network-scripts/ifcfg-ens256

# 编辑新配置文件（需修改关键参数，如NAME、DEVICE、IP、子网掩码等）
# 示例：通过vim编辑（也可使用sed/echo批量修改）
vim /etc/sysconfig/network-scripts/ifcfg-ens256
```
   - 概念说明：`INTERFACE`（网卡接口）是调用网络资源的方式，类似函数、API的作用。
3. 网卡开关与配置生效：
```bash
# 临时关闭指定网卡
ifdown ens256

# 永久关闭网卡（修改配置文件，设置ONBOOT=no 或 NM_CONTROLLED=no）
sed -i 's/ONBOOT=yes/ONBOOT=no/' /etc/sysconfig/network-scripts/ifcfg-ens256

# 重启网卡服务使配置生效
systemctl restart network

# 或重启单个网卡（先关后开）
ifdown ens256 && ifup ens256
```

### （四）其他基础配置
1. 本地光盘源设置：
   - 优势：NAT网卡关闭时仍可使用，比网络源更稳定；
   - 用途：保障软件安装（如httpd、tcpdump）不受网络限制。
2. 防火墙与SELinux关闭：
```bash
# 临时关闭防火墙
systemctl stop firewalld

# 永久关闭防火墙（开机不自启）
systemctl disable firewalld

# 临时关闭SELinux
setenforce 0

# 永久关闭SELinux（编辑配置文件，需重启生效）
echo "SELINUX=disabled" > /etc/selinux/config
# 或通过vim编辑（确保文件存在该配置项）
vim /etc/selinux/config
```
   - 说明：现阶段关闭是为避免阻止服务访问，后续将学习防火墙规则配置，关闭存在安全风险（暴露所有端口）。
3. 启动级别调整（RHEL/CentOS 7+）：
```bash
# 查看当前默认target（运行级别）
systemctl get-default

# 永久设置为多用户字符界面（级别3，加快启动速度）
systemctl set-default multi-user.target
```
   - 核心概念：`systemd`替代传统`init`，“运行级别”替换为`target`；级别3→`multi-user.target`（多用户字符界面），级别5→`graphical.target`（图形界面）。
4. 配置文件补充：刚装完的虚拟机若缺少`SELinux`配置，需手动编辑`/etc/selinux/config`添加`SELINUX=disabled`。

### （五）虚拟机批量配置技巧
- 不推荐克隆：易导致网卡关联问题；
- 推荐方式：
  1. 复制装机文件手动逐个安装（单台约6分钟）；
  2. 编写Shell脚本自动化配置（如批量设置网卡、关闭防火墙）；
  3. 复制配置文件简化操作（如批量分发yum源配置、网卡配置）。

# 三、网络基础核心知识
### （一）网卡与网络连接相关知识
1. 网卡名称规律：
   - 装系统前添加的第二张网卡：通常命名为`ens192`；
   - 装系统后添加的网卡：通常命名为`ens256`；
   - 关键：名称不影响使用，需确保配置文件与网卡名对应。
2. 多网卡与多局域网：
   - 核心目的：让虚拟机连接多个不同局域网（每张网卡对应一个局域网）；
   - 连通条件：设备IP与子网掩码匹配（处于同一逻辑子网），如同“同一班级的学员才能直接交流”；
   - 实验要求：4台虚拟机需配置相同网段，确保实验中设备间正常交互。

### （二）IP配置与连通性
1. IP配置原则：
   - 网段匹配：“仅主机”模式下需配置“66”段IP（如192.168.66.X），否则无法连通；
   - 模式说明：“仅主机”模式下设备无法访问公网，仅能在特定局域网内连通；
   - 配置方式：手动分配或`dhcp`自动获取，同一虚拟机多张网卡不建议连接相同网络（避免IP冗余）。
2. IP连通性测试：
```bash
# 测试两台虚拟机连通性（发送4个ping包，避免无限ping）
ping -c 4 192.168.66.192
```
   - 示例：IP为192.168.66.191和192.168.66.192（子网掩码255.255.255.0），处于同一逻辑子网，可相互ping通；
   - 扩展：多IP设备（如同时有“66”段和“246”段IP）的连通性将后续测试。
3. 连通性问题排查（如Xshell无法连接虚拟机）：
   - 检查虚拟机IP：是否正确且与连接方式匹配的网段一致；
   - 检查真实机IP：是否与虚拟机IP在同一逻辑子网，真实机IP若为169开头（自动私有IP），需手动分配IP。

### （三）网关与路由相关知识
1. 网关的功能与作用：
   - 核心定义：网关=默认路由，依赖路由器实现跨网段通信；
   - 通信规则：默认仅能连通同一逻辑子网IP（如“66”段仅能连“66”段），跨网段（如“66”→“77”段）需通过网关转发；
   - 网段要求：网关必须与本地设备在同一逻辑子网（通过IP+子网掩码计算网络地址），而非仅IP前3段相同；
     - 示例：本地IP=192.168.66.191，子网掩码=255.255.255.128，网络地址=192.168.66.128，网关需为192.168.66.129~254。
2. 网关的查看与配置：
```bash
# 查看路由表（含默认网关）
route -n

# 永久配置网关（编辑网卡配置文件）
echo "GATEWAY=192.168.66.100" >> /etc/sysconfig/network-scripts/ifcfg-ens160
# 重启网卡使配置生效
systemctl restart network

# 临时配置网关（重启后失效，适用于测试）
route add default gw 192.168.66.100

# 删除临时网关
route del default gw 192.168.66.100
```

# 四、常用网络命令及应用
### （一）ping命令（检测网络连通性）
```bash
# 核心语法与常用选项
ping -c 4 -i 2 -I ens160 192.168.66.192
```
- 核心协议：ICMP（网际控制报文协议）；
- 选项解释：
  - `-c 次数`：指定ping包数量（示例中为4个）；
  - `-I 网卡名`：指定发送ping包的网卡（示例中为ens160）；
  - `-i 间隔`：指定发送ping包的时间间隔（示例中为2秒）；
- 实操演示：多网卡设备需指定网卡才能确保连通，部分场景下仅特定网卡可与目标IP通信。

### （二）arp命令（查看IP与MAC地址映射）
```bash
# 查看ARP缓存表（IP与MAC地址对应关系）
arp -a

# 清空ARP缓存（排查IP冲突时使用）
arp -d 192.168.66.192
```
- 核心功能：显示当前网络中设备的IP地址与MAC地址对应关系；
- 应用场景：排查IP冲突、MAC地址绑定等网络故障，直观呈现网络分层协议中的地址转换逻辑。

### （三）域名解析相关命令与DNS、nslookup
```bash
# nslookup：简单域名解析测试
nslookup www.baidu.com

# dig：详细解析测试（指定DNS服务器）
dig www.baidu.com @192.168.26.2
```
- 核心需求：实现IP地址与域名的相互转换（依赖DNS域名系统）；
- 解析细节：
  - 正向解析：通过域名获取IP；反向解析：通过IP获取域名（二者可独立配置）；
  - 复杂映射：可能通过CName（别名）实现域名指向，最终解析到目标IP。

### （四）路由跟踪命令（traceroute/tracert）
```bash
# Linux下安装traceroute（默认可能未安装）
yum -y install traceroute  # RHEL 7
dnf -y install traceroute  # RHEL 8+

# 基础路由跟踪（默认UDP协议）
traceroute www.baidu.com

# 模拟Windows tracert（使用ICMP协议）
traceroute -I 192.168.66.192
```
- 核心功能：探测本地与目标机器之间的路由转发路径，显示转发层数；
- 协议差异：
  - 虚拟机（Linux）：`traceroute`默认UDP协议；
  - 真实机（Windows）：`tracert`使用ICMP协议；
- 结果说明：通常跟踪10-17个节点完成，部分节点因隐私/限制无法显示。

### （五）ss命令（查看网络连接状态）
```bash
# 常用组合：查看所有TCP连接（数字格式+进程信息）
ss -antp

# 查看UDP连接（添加-u选项）
ss -antpu

# 过滤指定端口（如80端口）
ss -antp | grep 80
```
- 核心优势：属于`iproute2`工具集，效率高于`netstat`（`netstat`需安装`net-tools`包），主流Linux默认预装；
- 选项解释：
  - `-a`：显示所有类型连接；
  - `-n`：以数字形式显示地址和端口（避免服务名解析）；
  - `-t`：仅显示TCP协议连接；
  - `-u`：仅显示UDP协议连接；
  - `-p`：显示关联的进程名和PID。

### （六）进程相关命令（ps、top、pstree）
#### 1. ps命令（静态查看进程）
```bash
# 常用选项：显示所有进程（含父进程ID）
ps -ef

# 过滤指定进程（如httpd）
ps -ef | grep httpd

# 查看进程状态（更详细）
ps aux
```
- 输出关键字段：
  - 用户名（进程管理者）、PID（进程ID）、PPID（父进程ID）；
  - CPU/内存使用率、终端状态、进程开始时间、启动命令；
- 进程状态标识：
  - R（运行态）、S（可中断睡眠）、D（不可中断睡眠）、Z（僵尸进程）、T（停止态）；
  - l（多线程）、<（高优先级）、+（前台进程组）。

#### 2. top命令（动态查看进程）
```bash
# 实时监控进程资源占用
top

# 快捷键：按P按CPU排序，按M按内存排序，按q退出
```
- 核心功能：实时刷新进程的CPU/内存使用率等数据，便于监控系统资源占用。

#### 3. pstree命令（树形展示进程关系）
```bash
# 树形展示所有进程的父子关系
pstree

# 显示PID（更详细）
pstree -p
```
- 核心功能：以树形结构呈现进程间的父子衍生关系，帮助理解系统进程启动与依赖逻辑（如1号进程衍生的子进程）。

### （七）服务安装与启动（以Apache为例）
```bash
# 安装Apache（RHEL 7用yum，RHEL 8+用dnf）
yum -y install httpd  # RHEL 7
dnf -y install httpd  # RHEL 8+

# 启动服务+开机自启（一键操作）
systemctl enable --now httpd

# 停止服务+取消自启（一键操作）
systemctl disable --now httpd

# 验证服务状态（查看80端口）
ss -antp | grep 80

# 验证进程（查看httpd进程）
ps -ef | grep httpd
```
- 选项解释：`-y`自动确认依赖项安装，无需手动交互；`enable --now`实现“立即启动+开机自启”。

### （八）tcpdump命令（网络数据包捕获）
#### 1. 核心功能
- 多维度筛选：按网卡、端口、协议等条件捕获数据包；
- 实时/离线分析：实时展示数据包细节，或保存为pcap文件供后续分析（支持Wireshark打开）；
- 格式优化：支持ASCII、十六进制等多种展示格式，适配不同调试场景。

#### 2. 常用命令示例（附解释）
```bash
# 1. 捕获5个数据包后停止
tcpdump -c 5

# 2. 捕获ens160网卡的SSH流量（22端口），数字格式显示IP/端口
tcpdump -n -i ens160 port 22

# 3. 实时查看HTTP流量文本内容（ASCII格式）
tcpdump -n -A port 80

# 4. 捕获ping对应的ICMP包
tcpdump -n icmp

# 5. 捕获指定IP的双向流量
tcpdump -n host 192.168.66.192

# 6. 捕获SSH流量并保存为pcap文件（供后续分析）
tcpdump -n -A -i ens160 -w ssh_cap.pcap port 22

# 7. 读取已保存的pcap文件
tcpdump -r ssh_cap.pcap

# 8. 复杂过滤：捕获ens160网卡、80端口、目标IP为192.168.66.192的流量
tcpdump -i ens160 -n port 80 and host 192.168.66.192

# 9. 捕获完整数据包（避免内容截断）+ 详细输出
tcpdump -s 0 -vv -n port 80
```

#### 3. 注意事项
- 权限要求：部分场景需用`root`用户执行（如捕获系统级流量）；
- 流量过滤：可组合多个条件（`and/or`）精准筛选；
- 性能影响：高流量场景下长时间抓包可能占用系统资源，建议结合`-c`（指定数量）或`-w`（保存文件）限制捕获范围。
