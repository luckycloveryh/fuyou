# 视频主要内容整合（无精简完整版）
## 一、前期核心知识回顾
### （一）基础命令与变量操作
1. **read命令：交互式接收用户输入**
    - 核心功能：脚本运行时弹出提示，获取用户输入并存储到变量中，支持多种实用选项。
    - 常用选项（含大白话解释+实操例子）：
        - `-t 秒数`：设置输入等待时间，超时脚本继续执行，可搭配`-p`添加提示语。例子：`read -t 10 -p "请输入一个数字（10秒内）：" n`（等待10秒，提示用户输数字，输入内容存入变量n）。
        - `-s`：隐藏输入内容（适用于密码等敏感信息）。例子：`read -s -p "请输入密码：" pwd`（输入密码时屏幕无字符显示）。
        - `-p "提示语"`：直接在输入前显示提示信息，无需额外echo命令。

2. **declare命令：查看与定义变量类型**
    - 核心功能：Shell默认变量为字符串类型，通过该命令可定义特定类型变量，或查看变量的类型与值。
    - 常用选项（含具体例子）：
        - `-p 变量名`：查看指定变量的“类型+值”（最常用）。例子：`declare -p n`（显示变量n的类型及具体值）。
        - `-i 变量名`：定义整数类型变量（仅整数类型可进行加减乘除运算）。例子：`declare -i sum=0`（将sum定义为整数，用于后续累加计算）。
        - `-a 变量名`：定义数组变量（可存储多个值）。例子：`declare -a arr=(1 2 3 4 5)`（定义数组arr，存储5个数字）。
        - `-x 变量名`：将变量设为环境变量（其他脚本可调用，等效于`export`命令）。例子：`declare -x PATH=$PATH:/home/user/bin`（扩展环境变量PATH）。
        - `-r 变量名`：将变量设为只读模式（定义后不可修改，修改会报错）。例子：`declare -r PI=3.14`（PI值固定，无法更改）。

3. **整数计算与变量操作**
    - 核心注意点：Shell默认变量为字符串，直接写`sum=sum+1`会报错，需用特定格式实现整数运算。
    - 常用计算方法（全版本覆盖）：
        - 基础运算：`$((表达式))`，例子：`echo $((2+3))`（输出5）、`sum=$((sum + i))`（sum与i累加后存回sum）。
        - 简写累加：`sum+=i`（与`sum=$((sum + i))`功能一致，语法更简洁）。
        - 自增自减：`i=$((i+1))`或`i++`（i加1）、`i=$((i-1))`或`i--`（i减1）。
    - 赋值规则：给`declare -i`定义的整数变量赋值时，直接写数值或运算表达式即可，无需额外格式转换。

4. **数组操作：变量存储多个值**
    - 数组定义：`数组名=(值1 值2 值3 ...)`，例子：`arr=(1 2 3 4 5)`（存储5个数字）。
    - 核心操作（含所有细节用法）：
        - 取所有值：`${数组名[*]}`或`${数组名[@]}`（前者将数组视为整体，后者可分开处理每个元素，大部分场景通用）。例子：`echo ${arr[*]}`（输出1 2 3 4 5）。
        - 取单个元素：数组下标从0开始（第一个元素下标为0）。例子：`echo ${arr[3]}`（取第4个元素，输出4）。
        - 取数组长度：`${#数组名[@]}`或`${#数组名[*]}`。例子：`echo ${#arr[@]}`（输出5，即数组元素个数）。
        - 取部分元素：`${数组名[起始下标 长度]}`（从起始下标开始，提取指定个数的元素）。例子：`echo ${arr[1 3]}`（从下标1（第二个元素）开始，取3个元素，输出2 3 4）；或`${数组名[4]:3}`（取第四个元素后剩余部分，按实际场景调整）。

### （二）判断相关：脚本的“选择逻辑”
1. **三大类判断场景（含语法与例子）**
    - （1）字符串判断（比较字符串或判断空值）：
        - 相等：`字符串1 == 字符串2`（必须用两个等号）。例子：`if [ "abc" == "abc" ]; then echo "相等"; fi`（输出“相等”）。
        - 不相等：`字符串1 != 字符串2`。例子：`if [ "abc" != "def" ]; then echo "不相等"; fi`（输出“不相等”）。
        - 判断为空：`[ -z 字符串 ]`（z=zero，长度为0则为空）。例子：`if [ -z "$str" ]; then echo "字符串为空"; fi`。
        - 判断非空：`[ -n 字符串 ]`（n=not zero，长度不为0则非空）。例子：`if [ -n "$str" ]; then echo "字符串非空"; fi`。
        - 多条件“与”：`条件1 -a 条件2`（两个条件均成立则为真）。例子：`[ "a" == "a" -a 1 -eq 1 ]`（“a等于a”且“1等于1”，条件成立）。
    - （2）数值比较（比较数字大小，不可用==）：
        - 相等：`-eq`（equal），例子：`[ 5 -eq 5 ]`（成立）。
        - 不相等：`-ne`（not equal），例子：`[ 5 -ne 3 ]`（成立）。
        - 大于：`-gt`（greater than），例子：`[ 5 -gt 3 ]`（成立）。
        - 小于：`-lt`（less than），例子：`[ 3 -lt 5 ]`（成立）。
        - 大于等于：`-ge`（greater or equal），例子：`[ 5 -ge 5 ]`（成立）。
        - 小于等于：`-le`（less or equal），例子：`[ 3 -le 5 ]`（成立）。
    - （3）文件类型判断（判断文件属性）：
        - 常用：`-f 文件名`（判断是否为普通文件，非目录、设备文件等）。例子：`if [ -f test.sh ]; then echo "是普通文件"; fi`（当前目录有test.sh则输出）。

2. **分支语句（if语句的三种写法）**
    - 单分支：满足条件才执行命令 → `if [ 条件 ]; then 命令; fi`。
    - 双分支：满足执行A，不满足执行B → `if [ 条件 ]; then 命令A; else 命令B; fi`。
    - 多分支：多个条件依次判断 → `if [ 条件1 ]; then 命令1; elif [ 条件2 ]; then 命令2; else 命令3; fi`。
    - 嵌套规则：if内部可嵌套if，但建议最多嵌套2-3层，嵌套过多需优化代码可读性。

### （三）正则表达式前期回顾
- 核心说明：正则表达式是“按规则匹配字符串”的工具，配合grep等命令使用，IP地址和邮箱的精确匹配较复杂，需课后自行梳理巩固。
- 学习铺垫：通过基础正则练习，为后续grep、awk等命令的文本筛选功能奠定基础。

## 二、核心脚本实验：计算1到用户输入数字的偶数和
### （一）实验目标
运行脚本后，用户输入一个正整数（如10），脚本自动计算1到该数字之间所有偶数的和（例：1到10的偶数和为2+4+6+8+10=30）。

### （二）完整实现步骤（从基础到优化，含踩坑提醒）
1. **思路梳理**
    - 接收用户输入的数字（用read命令）；
    - 遍历1到该数字的所有整数；
    - 判断每个数字是否为偶数；
    - 累加所有偶数，最终输出总和。

2. **步骤1：基础框架（用户输入+数字遍历）**
    - 脚本代码：
        ```bash
        #!/bin/bash
        # 计算1到n的偶数和（基础版-仅遍历）
        sum=0  # 总和初始为0（必须在循环外初始化，避免每次循环清零）
        read -p "请输入一个正整数：" n  # 接收用户输入，存入变量n

        # 遍历1到n的数字（踩坑提醒：大括号{1..$n}不识别变量，需用seq命令）
        for i in $(seq $n)  # seq $n生成1到n的数字序列，$(seq $n)获取序列给for循环
        do
            echo "当前遍历的数字：$i"  # 测试用，验证遍历是否正常
        done
        ```
    - 运行测试：保存为`sum_even.sh`，执行`bash sum_even.sh`，输入10，输出1到10的所有数字，说明遍历成功。
    - 关键踩坑：大括号范围`{1..$n}`无法识别变量n，只能写固定数字（如{1..10}），因此必须用`seq`命令生成动态序列。

3. **步骤2：添加偶数判断+累加（核心功能）**
    - 脚本代码（完整版）：
        ```bash
        #!/bin/bash
        # 计算1到n的偶数和（完整版-含判断+累加）
        sum=0
        read -p "请输入一个正整数：" n

        for i in $(seq $n)
        do
            # 偶数判断：i除以2余数为0（两种写法均可）
            if [ $((i%2==0)) ]  # 写法1：直接在$(( ))内写等于判断
            # 或 if [ $((i%2)) -eq 0 ]  # 写法2：用数值比较符号-eq
            then
                sum=$((sum + i))  # 累加偶数（或简写sum+=i）
                echo "当前偶数：$i，累计和：$sum"  # 测试用，查看累加过程
            fi
        done

        echo "------------------------"
        echo "1到$n的偶数和是：$sum"  # 输出最终结果
        ```
    - 运行测试：输入10，输出“当前偶数：2，累计和：2”→“当前偶数：4，累计和：6”...最终输出“1到10的偶数和是：30”，功能正常。

4. **步骤3：常见语法坑提醒（必避）**
    - 坑1：变量未加`$` → 如写`sum=(sum + i)`，Shell不识别sum和i为变量，报错；需写`$sum`、`$i`。
    - 坑2：单引号与双引号混用 → 单引号内变量不解析（`echo '$sum'`输出`$sum`），双引号内解析（`echo "$sum"`输出实际数值）。
    - 坑3：for循环未用`$(seq $n)` → 直接写`for i in seq $n`，Shell会把“seq”和“$n”当字符串，不生成数字序列。

5. **步骤4：脚本优化（无需判断，直接生成偶数序列）**
    - 核心思路：用`seq`命令直接生成1到n的偶数序列，跳过判断步骤，简化代码、提高效率。
    - `seq`高级用法：`seq 起始值 增量 终止值`，例子：`seq 2 2 10`（从2开始，每次加2，到10结束，生成2、4、6、8、10）。
    - 优化版脚本：
        ```bash
        #!/bin/bash
        # 计算1到n的偶数和（优化版-无判断）
        sum=0
        read -p "请输入一个正整数：" n

        # 直接生成偶数序列，遍历累加
        for i in $(seq 2 2 $n)
        do
            sum+=i  # 无需判断，直接累加偶数
        done

        echo "1到$n的偶数和是：$sum"
        ```
    - 运行测试：输入10输出30，输入7生成2、4、6，和为12，结果正确。

### （三）脚本运行完整流程（照做必成功）
1. 创建文件：`touch sum_even.sh`（终端执行，创建脚本文件）；
2. 编辑文件：`vim sum_even.sh`（用vim编辑，或用VS Code、记事本等）；
3. 复制粘贴优化版脚本，保存退出（vim中按ESC，输入`:wq`回车）；
4. 添加执行权限：`chmod +x sum_even.sh`（无权限无法直接运行）；
5. 运行脚本：`./sum_even.sh`（或`bash sum_even.sh`）；
6. 输入数字（如10），按回车，查看结果。

## 三、正则表达式详解（基础规则+实际应用）
### （一）核心定义
正则表达式是“按规则查找字符串”的神器，配合grep等命令可实现精准文本筛选，适用于文件检索、内容过滤等场景。

### （二）三大匹配规则
1. **字符匹配：找特定字符或一类字符**
    - 精确匹配：直接写目标字符，匹配包含该字符的内容。例子：`a` → 匹配所有包含“a”的行。
    - 范围匹配：`[字符集合]`，匹配集合中任意一个字符。例子：
        - `[abc]` → 匹配包含a、b、c中任意一个的行；
        - `[a-z]` → 匹配包含小写字母的行；
        - `[0-9]` → 匹配包含数字的行。
    - 排除匹配：`[^字符集合]`，匹配“不包含”集合中任意字符的内容（^在括号内表“排除”）。例子：`[^abc]` → 匹配不包含a、b、c的字符。
    - 任意字符：`.`（一个点），匹配除换行外的任意一个字符。例子：`a.b` → 匹配acb、adb、a1b等（a和b之间任意字符）。

2. **位置匹配：找特定位置的字符**
    - 行首匹配：`^`（尖角号），匹配行的开头。例子：`^a` → 匹配以“a”开头的行（如“abc”匹配，“xabc”不匹配）。
    - 行尾匹配：`$`（美元符号），匹配行的结尾。例子：`a$` → 匹配以“a”结尾的行（如“cba”匹配，“cabx”不匹配）。
    - 整行匹配：`^目标字符串$`，一行中仅包含目标字符串才匹配。例子：
        - `^ab$` → 仅匹配“ab”这一行（多一个字符都不匹配）；
        - `^$` → 匹配空行（一行无任何内容）。

3. **次数匹配：找出现特定次数的字符**
    - 核心注意：`?`、`+`、`{n1,n2}`在grep中默认不识别，需加`-E`选项（如`grep -E`）或用`\`转义（如`\?`），也可使用`egrep`命令。
    - 具体规则（含例子）：
        - `*`（星号）：匹配前面的字符0次或任意多次。例子：`ab*` → 匹配a、ab、abb、abbb...（b可出现0次到无数次）。
        - `?`（问号）：匹配前面的字符0次或1次（最多1次）。例子：`ab?` → 匹配a或ab；命令：`grep -E 'ab?' 文件名`。
        - `+`（加号）：匹配前面的字符1次或任意多次（至少1次）。例子：`ab+` → 匹配ab、abb、abbb...（不匹配a）；命令：`grep -E 'ab+' 文件名`。
        - `{n1,n2}`：匹配前面的字符n1到n2次。例子：
            - `ab{1,3}` → 匹配ab、abb、abbb（b出现1-3次）；
            - `ab{2}` → 匹配abb（b恰好出现2次）；
            - `ab{2,}` → 匹配abb、abbb...（b至少出现2次）；
            - 命令：`grep -E 'ab{1,3}' 文件名`（加-E识别{}）。

### （三）实际应用案例（直接可用）
- 需求：在`test.txt`文件中，查找“全是数字的行”。
- 正则表达式：`^[0-9]+$`（拆解：^行首 → [0-9]+至少1个数字 → $行尾）。
- 执行命令：`grep -E '^[0-9]+$' test.txt`。
- 结果：仅输出一行中全是数字的内容（如“123”“4567”，含字母/符号的行不显示）。

## 四、常用文本截取命令（grep、cut、awk）
### （一）grep命令：行提取工具
- 功能定位：在文件中查找符合条件的“整行”，逐行检索文件内容，核心用于“行筛选”。
- 搭配正则：常与正则表达式结合使用，实现精准行匹配（如上述“查找全是数字的行”案例）。

### （二）cut命令：列提取工具
1. 功能定位：提取文件中的特定列，或通过管道接收字符串并转化为文件处理，适用于列结构规律的场景。
2. 核心选项与用法（含例子）：
    - `-f 列号`：指定提取的列（列号从1开始）。
        - 例子：`cut -f2`（提取第二列）、`cut -f2,3`（提取第二、三列，列号用逗号分隔）、`cut -f2 3`（列号间可带空格，效果同上）。
    - `-d 分隔符`：自定义列分隔符（默认分隔符为制表符\t）。
        - 例子：`cut -d: -f1 /etc/passwd`（以冒号为分隔符，提取/etc/passwd文件第一列）；选项与参数间可无空格（`cut -d: -f1`）、带引号（`cut -d':' -f1`），灵活度高。
    - `-c 字符范围`：按字符个数提取，适用于列分隔不规律的场景（如多空格分隔）。
        - 格式：`-c5`（提取第5个字符）、`-c1-5`（提取1-5个字符）、`-c5-`（从第5个字符提取到末尾）、`-c-5`（从开头提取到第5个字符）。
        - 注意：英文/数字占1字节，汉字占2-3字节（编码差异），处理中文时需注意字符计数。
3. 应用场景示例：
    - 提取文件路径第四层级：`echo "/a/b/c/d/e" | cut -d/ -f4`（输出d，按实际路径层级调整列号）。
    - 小数取整：`echo "3.14" | cut -d. -f1`（输出3，提取整数部分；需四舍五入需额外写脚本）。
    - 处理`df -h`输出：`df -h | cut -c1-20`（提取前20个字符，解决多空格分隔的列提取问题）。

### （三）awk命令：行+列提取全能工具
1. 功能定位：兼具行提取和列提取功能，支持复杂条件判断和格式输出，工作原理是“逐行匹配处理文件内容”。
2. 语法格式：`awk '条件{动作}' 文件名`
    - 多条件动作：可写多个“条件{动作}”组合（如`awk '条件1{动作1} 条件2{动作2}' 文件名`）。
    - 省略规则：无条件则对所有行执行动作；无动作则默认打印符合条件的行。
3. 核心元素与用法（含例子）：
    - （1）内置变量：
        - `$n`：第n列（n为数字），`$0`表示整行。例子：`$2`（第二列）、`$2 "\t" $3`（第二列和第三列，制表符分隔）。
        - `FS`：列分隔符，可在动作中指定（`BEGIN{FS=":"}`）或用`-F`选项指定（`awk -F: '{print $1}'`）。
        - `NF`：当前行的总列数，`$NF`提取最后一列，`$(NF-1)`提取倒数第二列（无需手动算列数）。例子：`awk -F/ '{print $NF}' /a/b/c/d`（输出d，提取路径最后一层）。
        - `NR`：当前行号，用于按行号筛选。例子：`NR>2`（行号大于2）、`NR==3`（第三行）。
    - （2）动作与打印：
        - `print`：默认打印后换行，列间默认空格分隔。例子：`print $2, $3`（输出第二、三列，空格分隔）、`print $2 "\t" $3`（制表符分隔）。
        - `printf`：需手动指定格式和换行符，格式控制符`%s`表字符串。例子：`printf "%s\t%s\n", $2, $3`（第二、三列制表符分隔，换行）。
    - （3）条件判断：
        - 数值比较：支持`==`、`>`、`<`、`>=`、`<=`、`!=`。例子：`$4>80`（第四列数值大于80）。
        - 字符匹配：`~`（包含）、`!~`（不包含），匹配模式用`//`包裹。例子：`$2~/Linus/`（第二列含“Linus”）、`$2!~/x/`（第二列不含“x”）；模式含特殊字符需转义。
4. 应用场景示例：
    - 提取/etc/passwd第一列：`awk -F: '{print $1}' /etc/passwd`或`awk 'BEGIN{FS=":"}{print $1}' /etc/passwd`。
    - 提取df -h使用率列：`df -h | awk '{print $5}'`（自动识别空白分隔符）。
    - 筛选成绩大于80的学生：`awk '$4>80{print $2 "\t" $4}' cut.txt`（第二列学生名，第四列成绩）。
    - 多条件筛选：`awk '$2~/Linus/ && $3>=70{print $0}' cut.txt`（第二列含“Linus”且第三列≥70，打印整行）。

## 五、命令对比与适用场景
| 命令 | 核心功能 | 适用场景 | 优势 | 局限性 |
|------|----------|----------|------|--------|
| grep | 行提取 | 快速查找包含特定字符串/正则匹配的整行 | 速度快、语法简单，搭配正则灵活 | 仅能提取整行，无法单独提取列 |
| cut | 列提取 | 列分隔符固定或字符位置固定的场景（如冒号分隔、固定长度字符） | 操作简单、执行高效 | 不支持复杂条件判断，对不规律分隔处理弱 |
| awk | 行+列提取 | 列分隔不规律、需多条件筛选、复杂格式输出的场景 | 功能全面、灵活度高，支持正则和逻辑判断 | 语法相对复杂，需记忆内置变量和格式 |

## 六、学习建议与核心要点总结
### （一）学习建议
1. 正则表达式：重点练习IP地址、邮箱的精确匹配，自行梳理复杂正则的逻辑的；
2. 命令练习：用实际文件（`/etc/passwd`、自定义`cut.txt`）练习cut和awk的所有选项，尝试不同条件组合；
3. 脚本实践：亲手运行“偶数和脚本”，修改参数（如输入负数、小数）测试边界情况，加深对循环、判断的理解；
4. 后续规划：学习awk与正则表达式的结合使用，提升复杂文本处理能力。

### （二）核心要点总结（必须掌握）
1. read命令：`-t`（超时）、`-s`（隐藏）、`-p`（提示）选项的使用；
2. 变量操作：`declare -i`（整数）、`declare -a`（数组）、`$((...))`（整数运算）、`sum+=i`（累加）；
3. 循环遍历：`for+seq`生成动态数字序列，解决大括号不识别变量的问题；
4. 判断语句：字符串/数值/文件的判断语法，if的单/双/多分支结构；
5. 正则表达式：字符/位置/次数匹配规则，`grep -E`识别扩展正则；
6. 文本截取：grep（行提取）、cut（列提取）、awk（全能提取）的适用场景与核心用法；
7. 核心实验：偶数和脚本的基础版、优化版，以及常见语法坑的规避。
