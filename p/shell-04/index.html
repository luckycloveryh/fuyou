Shell 变量、特殊符号与 grep

介绍《Shell 变量、特殊符号与 grep》，涵盖特殊符号与grep命令、Shell中的特殊符号和Shell变量核心知识（深化与拓展）等实践要点。

2025/12/05 · 6282 字 · -- 次阅读

一、旧知识回顾

（一）特殊符号与grep命令

  1. 通配符与正则符号的区别：通配符（如[]代表范围内任意一个字符、*代表任意个字符）用于匹配文件名等，grep命令中使用的是正则符号。
  2. grep常用选项：-c统计匹配行数，-n显示匹配内容所在行号，-A（数字）显示匹配行及后续指定行数，-i忽略大小写，-v反选匹配内容。

（二）Shell中的特殊符号

  1. 反引号（`）与$()：均用于获取命令执行结果。
  2. 单引号与双引号：单引号内所有字符均为普通字符（所见即所得），双引号内特殊符号（如$、`）仍保留特殊含义。
  3. 括号：小括号()用于执行子shell命令，中括号[]用于测试表达式（判断条件是否成立，常与if、for结合，表达式需用空格分隔），大括号{}在Shell执行中具有特定含义。
  4. $符号相关：$?表示上一命令执行结果（0为成功，非0为失败），$$表示当前Shell进程号，$!表示最后一个后台进程号。

（三）变量基础

  1. 变量定义：变量名=值，变量名需满足“包含数字、字母、下划线，且不以数字开头”，若值含空格需用单/双引号包裹。
  2. 变量操作：修改变量直接重新赋值；删除变量用unset 变量名；查看变量用set，set -u可显示未定义变量的提示，set -x可显示脚本执行过程中的命令。

二、Shell变量核心知识（深化与拓展）

（一）变量分类与操作

  1. 自定义变量：用户自行定义，默认仅在当前Shell生效。
  2. 环境变量：系统或用户定义的全局变量（如PATH指定命令搜索路径、PS1定义命令提示符样式），用export 变量名=值定义，env | grep 变量名可查看，修改与删除操作同自定义变量。
  3. 位置参数变量：用于向脚本传递参数，$0代表脚本名，$1-$n代表第1到第n个参数，$#统计参数个数，$*和$@均代表所有参数（双引号中表现不同），第11个及以后参数需用${n}（如${11}）。

（二）变量类型与运算

  1. 默认类型：所有变量默认为字符串类型，即使赋值为数字，仍按字符串处理。
  2. 类型声明与查看（declare命令）：
    • -p 变量名：显示变量类型和内容（如declare -p num，输出declare -- num="10"为字符串类型，declare -i num="10"为整数类型）。
    • -i：声明整数类型（如declare -i sum=5+3，sum结果为8；未声明则sum=5+3为字符串“5+3”）。
    • -a：声明数组类型（用于存储一组数据）。
    • -x：声明环境变量（使变量可在子进程中生效，类似export，取消用declare +x 变量名）。
    • -r：声明只读变量（无法修改或删除，终端/脚本内临时生效，无直接取消命令，需重启终端/脚本）。
  3. 数值运算规则与方法：
    • 运算结果判定：字符串拼接仍为字符串；整数类型变量赋值运算时自动执行数值计算。
    • 运算方法：
      • 方法1：$((...))，如$((N1 + N2))。
      • 方法2：declare -i定义整数变量后直接赋值，如declare -i sum=0; sum=N1+N2。
      • 方法3：expr命令（运算符左右加空格，特殊符号需转义），如expr 10 + 20。
      • 方法4：let命令（支持简洁写法，适合自增自减），如let sum=N1+N2。
    • 运算优先级：先正负号，再小括号，接着乘、除、取余，最后加、减，符合数学逻辑。
    • 除法与取余特性：商的符号“同号为正，异号为负”；余数符号与被除数一致，范围为0到“除数减1”。
  4. 随机数生成：
    • 系统变量$RANDOM（范围0-32767，视频提及0-61535以实际系统为准）。
    • 指定范围生成：如0-100随机数$((RANDOM % 101))，10-120随机数$((RANDOM % 111 + 10))。
  5. 小数运算：需借助bc命令（需安装），如echo "1.2 + 3" | bc，scale=2控制小数位数（如echo "scale=2; 1.2/3" | bc）。

三、交互式参数传递：read命令详解

（一）基本用法

read 变量名：等待用户输入并存入变量，支持中文，解决位置参数变量需记顺序的问题。

（二）常用选项

  1. -p：直接添加提示信息，如read -p "请输入用户名：" username（无需额外echo）。
  2. -s：隐藏输入内容（适用于密码），如read -s -p "请输入密码：" password。
  3. -n 数字：限制输入字符数，如read -n 1 -p "请输入性别（m/f）：" gender（输入后直接执行后续命令）。
  4. -t 秒数：设置输入超时时间，如read -t 10 -p "请输入手机号（10秒内）：" phone（超时后变量值为空，脚本继续执行）。

（三）多值输入

  1. 语法：read -p "请输入姓名 年龄 地址：" name age addr（输入内容用空格分隔，依次存入变量）。
  2. 规则：输入值少于变量个数时，未匹配变量值为空；多于时，最后一个变量接收剩余所有值。

四、Shell数组操作

（一）数组定义

  1. 方法1：A2=(张三 李四 王五)（默认下标从0开始）。
  2. 方法2：declare -a A1（声明后逐个赋值A1[0]=张三; A1[1]=李四）。
  3. 方法3：单独指定下标赋值，如A3[0]=10; A3[1]=20（系统自动识别为数组）。

（二）数组查看

  1. 单个元素：echo ${数组名[下标]}，如echo ${A2[1]}（查看“李四”）。
  2. 所有元素：echo ${数组名[@]}或echo ${数组名[*]}（@将元素视为独立个体，*视为整体）。
  3. 数组长度：echo ${#数组名[@]}或echo ${#数组名[*]}，如echo ${#A2[@]}（3个元素结果为3）。
  4. 单个元素长度：echo ${#数组名[下标]}，如echo ${#A2[0]}（“张三”字符数为2）。

（三）数组修改与删除

  1. 修改元素：A2[1]=赵六（重新赋值指定下标）。
  2. 删除单个元素：unset A2[1]（删除指定下标元素）。
  3. 删除整个数组：unset A2（删除所有元素）。

（四）数组扩展与应用

  1. 扩展：直接赋值新下标添加元素，如A2[3]=冰雹（数组长度自动变为4）。
  2. 应用示例：随机抽取元素
    • 步骤：获取数组长度len=${#A2[@]}→生成0到len-1的随机下标rand_idx=$((RANDOM % len))→获取元素echo ${A2[$rand_idx]}（适用于随机提问等场景）。

五、Shell条件判断

（一）字符串比较

  1. 相等/不相等：==判断相等，!=判断不相等（如登录脚本中验证用户名）。
  2. 空字符串判断：
    • 方式1：[ "$str" == "" ]。
    • 方式2：-z（判断空）、-n（判断非空），如[ -z "$str" ]、[ -n "$str" ]。
  3. 实操注意：关注符号使用，可通过小括号整合多个判断条件。

（二）数值比较

  1. 常用运算符：-eq（等于）、-ne（不等于）、-gt（大于）、-ge（大于等于）、-lt（小于）、-le（小于等于）。
  2. 实操示例：获取/etc/passwd行数并判断，如[ $line -eq 20 ]（等于20）、[ $line -gt 25 ]（大于25），可扩展为用户输入文件名进行判断。

（三）多种条件组合判断

  1. 逻辑运算符：
    • -a（and）：多个条件同时满足，如[ $user == "root" -a $pass == "123" ]。
    • -o（or）：满足一个条件即可，如[ $user == "root" -o $pass == "123" ]。
    • 取反：!，如[ ! -z "$str" ]（判断非空）。
  2. 实操演示：通过登录脚本对比-a和-o的执行结果差异。

（四）文件类型判断

  1. 常见文件类型与判断选项：
文件类型 判断选项 说明 示例
普通文件 -f 存在且为普通文件 [ -f "/etc/passwd" ]
目录 -d 存在且为目录 [ -d "/home" ]
字符设备 -c 存在且为字符设备 [ -c "/dev/zero" ]
块设备 -b 存在且为块设备 [ -b "/dev/sda1" ]
链接文件 -L 存在且为链接文件 [ -L "/usr/bin/python" ]
套接字文件 -S 存在且为套接字文件 [ -S "/tmp/socket" ]
管道文件 -p 存在且为管道文件 [ -p "/tmp/pipe" ]
  1. 逻辑优化：先通过if-else嵌套演示，再引出if-elif-else语句简化代码，减少嵌套层级。

六、Shell分支语句

（一）单分支if语句

  1. 语法结构：if [ 条件判断 ]; then 执行逻辑; fi（仅条件成立时执行逻辑）。
  2. 示例：if [ $line -gt 25 ]; then echo "大于25"; fi。
  3. 简化写法：条件与逻辑较简单时可写在一行，如if [ $line -gt 25 ]; then echo "大于25"; fi（分号分隔各部分）。

（二）双分支if-else语句

  1. 语法结构：if [ 条件判断 ]; then 条件成立执行逻辑; else 条件不成立执行逻辑; fi。
  2. 示例：if [ -d "$file" ]; then echo "是目录"; else echo "不是目录"; fi（判断是否为目录）。

（三）多分支if-elif-else语句

  1. 语法结构：if [ 条件1 ]; then 执行逻辑1; elif [ 条件2 ]; then 执行逻辑2; ... else 所有条件不成立执行逻辑; fi。
  2. 示例：判断文件类型，依次判断目录、块设备、字符设备等，均不满足则输出“啥也不是”，可灵活调整分支顺序与数量。
  3. 注意事项：每个if/elif后需有条件判断，then后为执行逻辑，以fi结束，可添加用户提示扩展功能。

七、实战练习案例

（一）登录脚本（两种实现方式）

  1. 位置参数变量实现：
    • 需求：输入用户名（$1）和密码（$2），root+123提示登录成功（可加颜色\e[32m绿色、\e[0m默认），否则失败。
    • 实现：test或[]判断条件，echo输出结果，考虑参数为空的健壮性。
    • 优缺点：优点是非交互式交互，缺点是需记参数顺序，参数过多易用性差。
  2. read命令优化实现：
    • 优势：无需记忆参数顺序，交互更友好。
    • 实现：read -p提示输入用户名，read -s -p提示输入密码，逻辑判断与上述一致。

（二）计算1-10的和

  1. 需求：循环累加1到10的整数，预期结果55。
  2. 实现思路：
    • 定义累加变量sum（declare -i sum=0或sum=0）。
    • for循环遍历1-10（for i in {1..10}或for ((i=1; i<=10; i++))）。
    • 循环内累加：sum=$((sum + i))或let sum+=i。
    • 输出结果：echo "1-10的和为：$sum"。
  3. 示例脚本：
#!/bin/bash
declare -i sum=0
for ((i=1; i<=10; i++))
do
    sum+=i
done
echo "1-10的和为：$sum"

（三）文件类型判断脚本

  1. 需求：判断用户输入文件的类型，输出对应结果。
  2. 实现：使用if-elif-else语句，依次判断目录、块设备、字符设备等类型，均不满足则输出“啥也不是”。
