Linux 文件链接、复制与删除机制

整理Linux 文件链接、复制与删除机制 的核心概念、常用命令与实操步骤，适合作为学习和复习笔记。

2025/11/10 · 2301 字 · -- 次阅读

history #查看历史命令。 mount -t iso9660 /dev/sr0 /media/ #mount用于挂载-t指定光盘文件系统类型，/dev/sr0表示块设备文件，/media/表示挂载点。 rpm -ivh /media/BaseOS/Packages/t/tree-1.8.0-10.el9.x86_64.rpm #rpm命令可用于rpm包安装，i表示安装，v显示详细信息，h以#表示安装进度。

inode：文件权限、时间、所有者、所属组和文件保存占用block block：文件数据保存位置

创建文件：找到文件系统中可用的inode和block，进行写入数据。 复制：cp /root/a /opt/b 将现有文件block读取出来，写入到新分配的inode和block中。 剪切：跨分区/不跨分区 删除：将文件inode和block标为可用状态，等待后续覆盖式写入。

读写：文件名称—>inode–>block

文件名 inode block X 10 3 Y 10 Z 10

硬链接：创建文件用于记录当前现有文件的inode号 1.每创建一次硬链接，文件链接数量+1 2.硬链接文件之间每进行一次删除，文件链接数量-1，当文件链接数量为1时再次删除为永久删除。 3.互为硬链接的文件之间，修改任意一个其余均会发生变化。 4.硬链接无法跨分区创建。 5.不允许将硬链接指向目录

软链接（符号链接）：软链接是创建文件记录指定路径。 1.创建软链接建议使用绝对路径。 2.软链接和原文件之间inode不同。 3.软链接文件类型l，权限默认最大。 4.软链接创建不会让文件链接数量+1， 5.软链接删除，原文件不受影响。原文件删除，软链接变为失效状态。 6.软链接可以跨分区创建。 7.目录可以创建软链接。

6、 命令名称： tree（ 显示目录树）

命令格式： tree 目录

-d 只显示目录

（ 在 centos7&rocky9 下需要安装后才可使用）

6.5、 命令名称： pstree（ 查看进程树之间的关系）

格式： pstree [选项]

-A： 进程树之间的链接以 ASCII 码字符链接。-p： 同时列出每个进程的 PID。-u： 同时列出每个进程的所属账号名称。

7、 命令名称： cp（ 复制、 复制并改名）
命令格式： cp 源文件或目录 目标目录
-r 复制目录
-p 保留文件属性
-a 相当于-rp

8、 命令名称： mv（ 剪切、 改名）
9、 命令名称： rm （ 删除）
-r -f 删除目录强制删除

10、 命令名称： rmdir（ 删除空目录）
-p -v 递归删除空目录显示指令执行过程

11、 命令名称： cat（ 显示文件内容）

命令格式： cat 文件名

-n 列出行号

cat 显示多个文件内容

cat 将多个文件合并（ 按照文件先后顺序）

（       如文件超过一页内容后只能显示最后一页的内容）

12、 命令名称： more（ 分页显示文件内容）
b 空格 Enter q 或 Q 向上翻页（ 打开文件时使用）向下翻页换行退出

13、 命令名称： less（ 分页显示文件内容）

命令格式： less 文件名

显示文件内容的时候支持关键词查找。

14、 查看文件首部指定行： head

-n 数字 #查看文件指定首部 n 行。

15、 查看文件指定尾行： tail
-n 数字 -f #查看文件尾行。#持续显示文件变化情况。

16、 命令名称： ln（ 生成链接文件）

-s 创建符号链接

文件系统：

1.block： 文件系统中存储数据的最小单元， ext4、 xfs 等文件系统中， 创建时默认 4k，

分为存储文件数据的 data block 和存储目录数据的 directory block。

2.inode： 又称“ 索引节点” ， 每一个 inode 对应一个文件或目录， 记录了文件的大小、

所占用的 block 以及目录的 directory block 信息。

3.Inode Bitmap： 翻译成中文就是“ inode 位图” ， 用二进制的方式记录了 inode 的使

用情况。

4.Block Bitmap： 翻译成中文就是“ 块位图” ， 同 Inode Bitmap， 用二进制方式记录了

块的使用情况。
