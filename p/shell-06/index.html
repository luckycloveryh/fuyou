Shell 正则表达式与文本处理命令

介绍《Shell 正则表达式与文本处理命令》，涵盖正则表达式回顾与深入讲解、常用命令讲解和cut命令等实践要点。

2025/12/09 · 6623 字 · -- 次阅读

一、正则表达式回顾与深入讲解

  1. 基础匹配规则
    • 匹配单个字符：可使用.表示任意一个字符；若需匹配实际的.（如.com中的点），需进行转义。
    • 中括号[]：匹配括号内任意一个字符；若括号内开头加^，则表示匹配除括号内字符外的任意一个字符。
    • 多字符匹配：*可匹配前面字符的多个（包括0个），若需将多个字符视为整体（如ABC），需用小括号()包裹；+表示匹配前面字符至少一次，?表示匹配前面字符0次或1次；若需匹配指定次数，可使用大括号{}，如{n}表示匹配n次。
    • 逻辑或匹配：使用管道符|表示“或”关系，为避免与前面内容混淆，可结合小括号()界定范围，例如(a|b)表示匹配a或b，(abc|def)表示匹配abc或def。
    • 位置定位：^用于匹配行开头，$用于匹配行结尾；^$组合可匹配空行。
  2. 基础正则与扩展正则区分
    • 基础正则中，部分符号（如?、+、|等）无法直接被grep识别。
    • 解决方法：一是使用支持扩展正则的命令（如egrep）；二是在grep中对扩展正则符号进行转义；三是部分命令（如awk、sed）本身支持扩展正则，无需额外处理。

二、常用命令讲解

（一）cut命令

  1. 核心功能：截取文件中的列，操作对象为文件。
  2. 常用选项
    • -f：指定需截取的列号，如-f3表示截取第3列，多列用逗号分隔（如-f1,3）。
    • -d：指定列分隔符，默认识别制表符，若分隔符为斜线/、冒号:等，需用该选项指定，如-d:表示以冒号为分隔符。
    • -c：按字符截取，如-c1-20表示截取前20个字符，计数从1开始，不可写0。

（二）awk命令

  1. 基础语法：awk '条件{动作}' 文件名，其中条件和动作可根据需求组合，单引号''用于界定awk的指令部分。
  2. 内置变量
    • $0：表示当前行的所有内容。
    • NR：表示当前行号。
    • NF：表示当前行的总列数，可用于定位列，如$NF表示最后一列，$(NF-2)表示倒数第三列。
  3. 条件与动作
    • 数值比较条件：可进行大于（>）、小于（<）、等于（==）等比较，例如筛选“当课成绩大于80”的记录，条件可写为$NF>80（假设成绩在最后一列），动作可搭配print打印指定列（如print $1, $NF打印姓名和成绩）。
    • 字符包含条件：使用~表示“包含”，如$NF~8表示最后一列包含数字8；若需匹配任意列包含指定内容，可直接写/指定内容/（默认匹配整行，即$0~指定内容）。
    • 正则结合条件：条件中可嵌入正则表达式，如$0~/[0-9]+/表示匹配包含至少一个数字的行。
  4. 实际应用案例：以监控根分区使用率为例，通过df -h | awk '$NF=="/"{print $(NF-1)}'可提取根分区使用率；若需进一步处理（如判断使用率是否超过阈值），可将结果赋值给变量，结合条件判断：若$usage为整数，可使用if [ $usage -gt 25 ]; then ...；若$usage为小数，[]中的整数比较运算符不支持小数，需使用awk进行比较（如echo "$usage" | awk '$1>25 {print "使用率超过阈值"}'），并通过转义控制输出颜色（如红色提示高使用率）。
  5. 工作原理：按行读取数据，先判断是否有预定义条件（BEGIN和END），再根据自定义条件判断是否执行对应动作，处理完一行后继续读取下一行，直至所有数据处理完毕。
    • BEGIN：在读取数据前执行，仅执行一次，可用于初始化变量、打印表头。
    • END：在所有数据处理完成后执行，仅执行一次，可用于汇总计算结果（如求平均值、总和）。
    • 自定义条件：每行数据都会进行判断，满足条件则执行对应动作，可多个自定义条件按顺序执行。
  6. 进阶操作
    • 变量传递：外部变量传递给awk时，需注意单引号的“所见即所得”特性，可通过外层双引号或-v选项实现，例如name="小钱"; awk -v n="$name" '$0~n{print $0}' 文件名。
    • 运算功能：支持加减乘除运算，可用于计算列的总和、平均值等，例如计算学生成绩总和：awk 'NR>1{sum+=$3} END{print sum}' 成绩表；计算平均值时可结合小数处理，但默认不四舍五入，需额外处理保留小数位。
    • 格式对齐：直接提取多列时可能因列长度不一致导致显示不对齐，需结合其他功能（如格式化输出命令）优化显示效果。

（三）tr命令的功能与应用

  1. 大小写替换：tr命令可实现大小写转换，例如将输入中的小写字母全部转换为大写，或反之，在处理用户输入（如判断yes/no时忽略大小写）场景中非常实用。
  2. 删除字符：能删除指定字符，如在截取网卡等信息时，若出现多余空格影响后续配置文件使用，可通过tr命令删除空格；也可删除其他指定字符（如字母s）。

（四）sort命令的使用

  1. 基本排序与选项：sort命令用于对文件内容排序，默认按第一列、ASCII表顺序排序。常用选项包括：
    • -f：忽略大小写排序。
    • -b：忽略前面的空白，按第一个非空字符排序。
    • -u：删除所有重复项（无需重复项连续，命令会先排序再去重）。
    • -t：指定分隔符，结合-k可按指定列排序（如-t: -k3表示以冒号为分隔符，按第三列排序）。
    • -n：按数字大小排序（默认按字符比较，如39会比4小，用-n可修正）。
    • -r：反向排序（默认升序，-r改为降序）。
  2. 排序规则：默认按ASCII表顺序，符号在字母前，数字在符号后；按列排序时，先比较指定列的第一位字符，若相同再比较第二位，以此类推。

（五）uniq命令的功能与应用

  1. 基本去重：uniq命令用于去除文件中的重复项，但仅对连续的重复项有效，若重复项不连续，需先使用sort命令排序后再用uniq去重。
  2. 常用选项：
    • -i：忽略大小写去重。
    • -c：统计重复项的出现次数，并将相同项合并显示次数。
  3. 与sort的结合：sort命令的-u选项也能去重，且可直接处理非连续重复项，在某些场景下比uniq更便捷，但uniq的-c选项在统计重复次数时更有优势。

（六）sed命令相关应用

  1. sed命令判断纯数字输入：通过sed命令将输入中的非数字字符替换为空，若替换后结果为空字符串，则说明输入为纯数字；若结果非空，则不是纯数字。可结合条件判断，根据是否为纯数字执行不同操作。
  2. 文件内容非交互式增删改查
    • 基础语法：操作格式为sed [选项] '动作' 文件名，动作需用单引号包裹，支持类似AWK的变量传递（需额外嵌套单引号），也可通过-f选项指定脚本文件。核心选项包括-n（只显示操作影响的行，不显示全文）、-i（直接修改原文件内容，无此选项时仅显示效果，不修改原文件）。
    • 查询（查看）功能：按行号查看可通过np（n为行号）查看指定行（如3p查看第3行）、n,mp查看行号范围（如1,3p查看1-3行），多单行用分号分隔（如1p;3p查看1行和3行）；按条件查看支持按内容匹配（如包含“x”或“5”的行），也可结合正则表达式（需注意转义，如匹配包含5或8的行需特殊处理，类似grep的正则逻辑）。
    • 添加功能：追加（a）格式为na 内容（如3a new line在第3行后追加“new line”），插入（i）格式为ni 内容（如3i insert line在第3行前插入“insert line”），均支持\t（制表符）、\n（换行符）设置格式。
    • 删除功能：通过nd（n为行号）删除指定行（如3d删除第3行），n,md删除行号范围（如1,3d删除1-3行），无-i选项时仅显示删除效果，不修改原文件。
    • 修改功能：整行替换（c）格式为nc 新内容（如4c replace line将第4行替换为“replace line”），支持一行换多行；字符串替换（s）格式为[行范围]s/旧字符串/新字符串/[选项]，行范围可指定单行、多行或%（所有行），选项包括g（替换行内所有匹配项，默认只替换第一个）；正则替换支持用正则匹配目标内容（如将所有数字替换为“w”，需用[0-9]\+匹配连续数字，并注意转义），可结合g选项实现全局替换。
  3. 网卡配置脚本编写
    • 回顾与需求提出：先回顾sed命令用于修改文件内容的功能，随后提出脚本编写需求——找到当前正在使用且排除本地回环的第一张网卡，修改其IP地址获取方式（若为手动指定（Manual）则改为自动分配，反之亦然）。
    • 网卡与配置文件定位：探讨如何确定正在使用的网卡，提及可通过命令查看网卡状态（如有无IP地址判断是否启用），并指出网卡配置文件位于/etc/network目录下，同时思考如何定位具体配置文件（如区分不同版本的配置文件）。
    • 脚本编写关键步骤：通过命令获取IP相关行，确定网卡信息，将结果赋值给变量，以便后续操作；找到对应网卡配置文件后，使用sed命令修改IP获取方式相关配置，如替换手动（Manual）为自动获取相关设置，还可通过注释不需要的配置项来调整；强调使用sed命令的-i选项可直接修改原文件，修改后需重新加载配置才能使新设置生效。

（七）printf命令（AWK辅助格式化输出工具）

  1. 基础功能：操作对象为字符串，核心作用是先取消字符串原有格式，再按指定类型和格式输出。支持三种数据类型：%s（字符串类型）、%d（整数类型）、%f（浮点/小数类型），可通过这些符号定义列的类型，一个符号代表一列。
  2. 格式控制
    • 分隔符与换行：列之间可用\t（制表符）分隔，行之间可通过换行符实现每行单列或多列显示，多列时需对应多个格式符号。
    • 对齐与列宽：在格式符号（如%s、%d、%f）前后添加数字可设置列宽，正数表示右对齐，负数表示左对齐（如%40s表示列宽40且右对齐，%-40s表示列宽40且左对齐）。
    • 小数位控制：对于浮点类型%f，可通过%.n（n为数字）指定保留小数位数，且会自动进行四舍五入（如%.2f保留2位小数，%.0f保留整数）。
  3. 实际应用场景
    • 数据截取与格式调整：可结合AWK截取文件中的指定列（如第一列和倒数第二列），通过printf设置格式（如列宽、对齐方式），使输出更规整。
    • 平均值计算与格式化：计算数据平均值（如学生成绩平均分）后，用printf指定小数保留位数，同时可通过NR>1（AWK内置变量，NR表示行号）过滤表头行。

三、系统资源监控与数据处理

  1. 内存使用率计算
    • 使用free -h命令获取内存信息（更适合人类阅读，不可直接用于数值计算）；计算使用率时需使用free -m（以MB为单位）或free -b（以字节为单位）获取纯数字数据，结合AWK提取总内存、已用内存列，通过公式(已用内存/总内存)*100计算使用率，并用printf格式化输出（如保留1位小数、添加百分号）。
    • 可设置阈值条件，判断使用率是否超过预设值，后续可扩展为超阈值时输出红色提示。
  2. CPU使用率计算
    • 通过top -n 1（动态命令，-n 1表示只刷新一次）获取CPU信息，提取用户使用、系统使用相关数据，计算总使用率（用户使用+系统使用），同样用printf格式化输出并处理小数问题，便于与阈值比较。
  3. 数据类型转换与比较：系统命令输出的资源使用率常为小数，需通过printf将其转换为指定格式（如整数或固定小数位），解决AWK中整数比较无法处理小数的问题。

四、文件类型判断与条件脚本编写

  1. 文件类型判断选项
    • -f：判断文件是否存在且为普通文件。
    • -b：判断是否为块设备文件。
    • -c：判断是否为字符设备文件。
    • -d：判断是否为目录。
    • -s：判断文件是否存在且内容非空。
    • -e：判断文件是否存在（仅判断存在，不区分类型）。
  2. 条件脚本编写
    • 编写脚本时，可结合上述选项判断文件类型或状态，如判断文件是否存在，若存在再判断是否为普通文件、内容是否非空等。
    • 处理文件不存在的情况，需在脚本中添加相应的提示逻辑，例如当-e条件不成立时，输出“文件不存在”。
    • 以监控服务为例，可将服务状态结果输出到文件，通过-s判断文件是否非空，进而确定服务是否开启（如文件非空表示服务开启），并可将文件名定义为变量，方便修改和维护。

五、其他相关内容

  1. 内存与CPU使用率监控思路补充：监控内存使用率可通过free命令（推荐free -m/free -b）获取内存总容量、已使用容量等纯数字数据，结合awk提取关键数值并进行运算（如使用率=已使用/总容量*100）；CPU使用率监控需进一步学习相关命令和数据处理方法。
  2. 问题与解决方向：awk存在两个待解决问题，一是多行不规律数据的处理与显示对齐问题，二是小数运算后的保留小数位问题，后续将针对这两个问题展开讲解。
  3. 工具对比与适用场景
    • AWK、grep、cat 侧重数据提取和截取，不修改原文件；sed 侧重文件内容的非交互式增删改，可修改原文件。
    • 实际应用中，常结合AWK（数据计算与截取）和sed（内容修改），或用printf（格式化）优化输出，满足系统监控、数据处理、配置文件修改等需求。
  4. AWK核心要点总结
    • 内置变量NR（行号）用于过滤行（如NR>1跳过表头），支持预定条件（如行号、内容匹配）和自定义条件（如计算结果判断）。
    • printf 依赖类型（%s/%d/%f）和格式（列宽、对齐、小数位）实现规整输出，是AWK数据处理的重要辅助工具。
  5. sed核心要点总结
    • 非交互式操作，适合写入脚本自动化处理文件；-i选项需谨慎使用（直接修改原文件），建议先无-i查看效果。
    • 增删改查操作均围绕“行”或“内容匹配”展开，支持正则表达式，需注意特殊字符的转义规则。
