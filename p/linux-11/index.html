Linux 常用命令：目录、文件与路径基础

整理Linux 常用命令：目录、文件与路径基础 的核心概念、常用命令与实操步骤，适合作为学习和复习笔记。

ls -l /usr/bin/ 命令 [选项] [执行对象]

用户家目录：root用户在/root/ 普通用户在/home/

文件类型：普通文件、目录文件、块设备文件、字符设备文件 -rw—––. 1 root root 1207 10月 10 2024 anaconda-ks.cfg 第一个字符表示文件类型（Linux中不以后缀名决定文件类型） -表示普通文件 d表示目录 b表示块设备文件

从第二个字符开始连续9位字符表示文件权限： 读 写 执行 不具备某项权限 r w x -

文件所有者：默认创建文件的用户是文件所有者 文件所属组：默认创建文件时用户所在的组 文件其他人：既不属于所有者也不在所属组的用户

组：拥有相同权限用户的集合。

.表示SELinux，SELinux是Linux系统中默认存在的安全增强工具。

链接数量：

用户名 组名

inode：文件权限、时间、所有者、所属组和文件保存占用block block：文件数据保存位置

在创建目录是默认目录中以.记录当前目录inode号以..记录上级目录inode号。 绝对路径：在路径表达中以根为起始字符的表达方式。 相对路径：在路径表达中不以根为起始字符的表达方式。

1、 命令名称： ls（ 显示目录文件）

命令的格式： 命令 [-选项] [参数（ 执行对象） ] -a 显示所有文件， 包括隐藏文件

-l 详细信息显示

-d 查看目录属性

-h 文件大小显示为常见单位

-i 查询文件的 inode 号

-R 递归显示目录及其子目录

-n 显示文件的 UID 和 GID

2、 命令名称： touch（ 创建空文件/更新修改和访问时间）

命令格式： touch 文件名

Linux 文件命名规则：

（ 1） 除了/之外， 所有字符都合法。

（ 2） 有些字符最好不用。

（ 3） 避免使用.作为普通文件开头。

（ 4） Linux 严格区分大小写。

（ 5） 长度不能大于 255 字符。

3、 命令名称： mkdir（ 创建新目录）

命令格式： 命令： [-选项] [参数]

-v 显示创建过程

-p 递归创建

4、 命令名称： cd（ 切换目录）

命令格式： 命令 [-选项] [参数]

语法： cd 目录
cd cd cd ~ 进入当前用户的家目录- 进入上次目录.. 返回上一级目录
cd ../.. 返回上两级目录
cd . 进入当前目录

5、 命令名称： pwd（ 显示当前所在目录）

6、 命令名称： tree（ 显示目录树）

命令格式： tree 目录

-d 只显示目录

（ 在 centos7&rocky9 下需要安装后才可使用）
