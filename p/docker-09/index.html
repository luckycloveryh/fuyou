三. 容器的管理

Docker 命令行参数

Docker 操作命令分为: 管理命令与普通命令

  1. 管理命令：为区分每个项目的命令, 比如说镜像操作, 就是以docker image 开头
  2. 普通命令：是在docker 命令之后直接的命令, 比如说删除镜像 docker rmi
  3. 管理命令相对于普通命令更清晰、严谨。

Docker C/S 模式 （了解）

Docker 客户端和服务端是使用 Socket 方式连接，主要有以下几种方式:

1） 本地的 socket 文件 unix:///var/run/docker.sock （默认）

2） tcp://host:prot （演示）

3） fd://socketfd

  • Docker 默认连接方式
